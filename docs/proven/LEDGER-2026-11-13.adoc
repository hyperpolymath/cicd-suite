= Proven CI/CD programme: inventory ledger, 2026-11-13

This ledger merges what six estate sessions reported on 2026-11-13 between
15:55 and 15:59 UTC. Nobody re-surveyed for it. Each row names its source. A
row is a report, not a verification: where a source said "not read" or
"unexamined", this ledger says so too.

  `hypatia_rules_praxis.deed`).
* *COV*: the coverage thread (`hypatia` `docs/reports/coverage-matrix/matrix.json`,
  the 75 rows with route `first-line`).
* *D16*: the Doctrine 16 sweep, a red census of 35 repositories taken from
  default-branch heads at about 15:20 UTC.
* *WAVE*: the template upgrade wave.

== Classes

[cols="1,5"]
|===
| a | A fix exists but is not merged. The owner merges.
| b | No fix exists.
| c | Owner only: a setting, a secret, a security decision or credits.
| d | Should become proven content in this repository.
|===

A row can carry more than one class. "d" is added wherever a rule or template
that this repository should own would prevent the failure from coming back.

== Rule ids

The stable key is the A5 string `hypatia/<module>/<name>` (HYP, EXP). Short
codes such as WF029 and WH007 stay as aliases, and so do squabbler ids
`SQ-<FAMILY>-NN`. CASE-NNN numbers identify experiments, not rules. New ids are
minted through chora-registry with the A5 string as the key (V9).
